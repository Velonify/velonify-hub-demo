# Velonify Hub – Demo

Öffentliche Demo des Velonify Hub mit der erfundenen Agentur „Kranich Commerce“. Läuft komplett im Browser: kein Server, keine echten Daten, jede Besucherin hat ihre eigene Kopie, „Demo zurücksetzen“ startet neu.

Der Code liegt in [Velonify/velonify-crm](https://github.com/Velonify/velonify-crm) (Demo-Daten: `src/data/demo/`). Dieses Repo baut ihn nur ohne Zugangsdaten und veröffentlicht ihn per GitHub Pages: **Actions → Demo veröffentlichen → Run workflow** (Branch wählbar, Standard über die Repo-Variable `HUB_REF`, sonst `main`).
